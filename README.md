## 💻 Cara Menjalankan Proyek Secara Lokal
1. Buka folder proyek di teks editor (misalnya VS Code).
2. Buka berkas `index.html` secara langsung di browser Anda, atau gunakan ekstensi **Live Server** di VS Code.
3. Nikmati tampilan portofolio dengan efek suara Lo-Fi dan animasi laut dalam!

## 🌐 Menghubungkan ke GitHub

Jika Anda ingin mengunggah repositori ini ke akun GitHub Anda:

```bash
# 1. Pastikan Anda telah berada di direktori proyek
git branch -M main

# 2. Hubungkan ke repositori GitHub Anda (ganti <username-anda> dan <nama-repo>)
git remote add origin https://github.com/<username-anda>/my-porto.git

# 3. Unggah seluruh kode ke GitHub
git push -u origin main
```
